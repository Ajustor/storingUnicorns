storingUnicorns

Un client de bases de données léger, construit en Rust.

Une interface graphique rapide, inspirée de DataGrip, pour parcourir vos tables, écrire du SQL et modifier vos données — et la même chose dans le terminal, pour ceux qui n'en sortent jamais.

Installer en une ligne

Le script télécharge le binaire de votre système, vérifie son empreinte SHA-256 et l'ajoute à votre PATH.

Linux / macOS

curl -fsSL https://ajustor.github.io/storingUnicorns/install.sh | sh

Windows (PowerShell)

irm https://ajustor.github.io/storingUnicorns/install.ps1 | iex

Ensuite : storingUnicorns ouvre l'interface graphique, storingUnicorns tui l'interface terminal, storingUnicorns update met à jour.

Télécharger la v{{version}}

Choisissez le fichier de votre système. Une fois installé, storingUnicorns se met à jour tout seul : il vérifie au démarrage si une nouvelle version existe et contrôle chaque téléchargement par son empreinte SHA-256.

    {{downloads}}

macOS : ouvrez le .dmg et glissez storingUnicorns dans Applications. L'app n'est pas notarisée par Apple : au premier lancement, faites clic droit › Ouvrir (ou Réglages Système › Confidentialité et sécurité › Ouvrir quand même). Sous macOS 26 (Tahoe), installez-la dans le dossier Applications de votre dossier personnel (~/Applications, à créer s'il n'existe pas) : depuis /Applications, macOS 26 la bloque sans rien afficher. Linux : rendez l'AppImage exécutable avec chmod +x storingUnicorns-linux-x64.AppImage puis lancez-la (FUSE est nécessaire : paquet libfuse2 ou fuse). Les binaires seuls servent en ligne de commande (storingUnicorns tui). Windows : l'installateur .msi installe pour tous les utilisateurs ; le .exe est une version portable, sans installation.

Tout ce qu'il faut, rien de plus

  • 🔌 Connexions

    • PostgreSQL, MySQL, SQLite, SQL Server
    • Azure SQL : identifiants, Azure AD ou identité managée
    • Plusieurs connexions ouvertes à la fois, chacune avec sa couleur
    • Explorateur : schémas, tables, colonnes, clés et index

  • ✏️ Consoles SQL

    • Instruction ou bloc BEGIN … COMMIT au curseur Ctrl+Entrée
    • Un onglet de résultat par instruction, journal « Sortie »
    • Formatage Ctrl+Alt+L, historique Ctrl+Alt+E
    • Autocomplétion des tables et colonnes, annulation Échap

  • 📊 Éditeur de données

    • Pagination, filtre WHERE et tri ORDER BY
    • Tri par clic sur l'en-tête de colonne
    • Modifier, ajouter et supprimer des lignes directement dans la grille
    • Submit en une seule transaction, ou Revert

  • 🔍 Inspection

    • Panneau de valeur, JSON mis en forme
    • DDL de la table, recherche de table Ctrl+N
    • Structure : ajouter, renommer, modifier, supprimer une colonne

  • 📦 Import / export

    • Export CSV ou SQL INSERT
    • Import CSV avec mise à jour par identifiant et progression
    • Export, import et vidage de plusieurs tables d'un coup

  • 🖥️ Terminal

    • Toute l'application au clavier : storingUnicorns tui
    • Mêmes connexions que l'interface graphique
